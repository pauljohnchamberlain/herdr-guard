# Scope comparison

Herdr Guard is intentionally a small complement to existing Herdr tools:

| Tool | Focus | Herdr Guard’s boundary |
|---|---|---|
| Herdr Remote | Remote monitoring and control workflows | Local external-agent control with exact target proposals |
| Herdr Codex App | Codex-oriented chat synchronization | Agent-neutral snapshots, typed policies, and receipts |
| Official inside-pane skill | Control from an agent running inside Herdr | Control from an external coding-agent process |

These tools solve different problems. Herdr Guard does not replace Herdr’s
socket, CLI, persistence, or agent integrations.
